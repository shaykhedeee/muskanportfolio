# Recommended Tech Stack and Architecture

## Framework

### Next.js 16.x App Router
Use the latest secure 16.x patch available at implementation time.

Why:
- excellent image and metadata support
- server components for content-heavy pages
- route-level code splitting
- easy Vercel deployment
- strong dynamic routing for project case studies
- clean integration with Sanity

## UI runtime

### React 19.3+
Use stable View Transitions for project/category navigation where practical, with a normal navigation fallback.

## Language

### TypeScript
Strict mode enabled.

## Styling

### Tailwind CSS 4
Use Tailwind for layout, responsive rules and design tokens, but keep complex editorial shapes in scoped CSS/SVG where that is clearer.

Use CSS custom properties for brand tokens so motion code can share them.

## Motion

### GSAP + ScrollTrigger / Observer
Responsibilities:
- detect deliberate wheel/touch intent on desktop
- animate section entrance/exit
- pin or choreograph project rail
- draw SVG plan lines
- coordinate micro-interactions

### Lenis
Responsibilities:
- smooth native scrolling
- reliable programmatic `scrollTo`
- scroll anchors
- graceful scroll control without transform-based fake scrolling

Do not let GSAP and Lenis both own the same animation. GSAP observes and choreographs; Lenis performs the main scroll movement.

## Route transitions

### React View Transitions
Use project thumbnail → project hero transitions where supported.

Fallback:
- opacity/translate transition
- immediate route navigation if reduced motion is enabled

## Content

### Sanity + `next-sanity`
Use Sanity for:
- projects
- galleries
- experience
- style showcases
- resume and contact metadata

For the first visual build, seed local TypeScript fixtures that mirror the Sanity schema; swap the data source after the interface is approved.

## Images

- Sanity Image CDN for CMS media
- Next.js `<Image>` for responsive rendering, lazy loading and layout stability
- AVIF/WebP where generated by the pipeline
- use `sizes` properly per card
- preload only the first hero image

## Icons

- `lucide-react`
- custom SVG only for signature drafting/furniture icons

## Forms

- React server action or route handler
- Zod validation
- Resend for email delivery
- Cloudflare Turnstile for bot protection

## Hosting

### Vercel
Recommended production host.

Use:
- preview deployments for every pull request
- production domain
- Web Analytics
- Speed Insights

## Source control

- GitHub
- `main` = production
- `develop` optional only if a team needs it
- feature branches for major screens

## Package manager

### pnpm

## Runtime

### Node.js 24 LTS
Use the current Node 24 LTS patch unless Next.js/Vercel documentation specifies a newer supported LTS at setup time.

## Testing

- Playwright — navigation, project routes, scroll controller, contact form
- `@axe-core/playwright` — automated accessibility checks
- Lighthouse / PageSpeed for performance checks

## Analytics

- Vercel Web Analytics for privacy-friendly page/event analytics
- Vercel Speed Insights for field performance

Recommended custom events:
- `project_open`
- `category_open`
- `resume_download`
- `contact_click`
- `linkedin_click`
- `style_showcase_open`

## SEO

Use Next.js metadata APIs:
- unique title / description per project
- Open Graph image
- sitemap
- robots
- canonical URLs
- Person schema
- ProfilePage schema where appropriate
- BreadcrumbList on project/category pages

## Performance architecture

Avoid:
- Three.js unless a later concept genuinely needs it
- autoplay background video in the hero
- loading all 5 full-resolution project images immediately
- giant PNG moodboards where compressed AVIF/WebP can be used

Targets:
- LCP <= 2.5s on typical mobile connection
- CLS <= 0.1
- INP <= 200ms
- hero visual loaded first; all below-the-fold media lazy loaded

## Suggested dependencies

```bash
pnpm add gsap lenis lucide-react next-sanity @sanity/image-url @portabletext/react zod resend @vercel/analytics @vercel/speed-insights
pnpm add -D prettier prettier-plugin-tailwindcss playwright @axe-core/playwright
```
